# Data Quality Rule Engine

## Requirements
- Java 21

## Run the demo
From the project root:
```bash
./gradlew :rule-engine-demo:bootRun
```
Swagger UI: `http://localhost:8080/swagger-ui.html`


## Run tests
```bash
./gradlew test
```
